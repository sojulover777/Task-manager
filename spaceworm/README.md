# SpaceWorm

Space Worm is a drop-in-ready user interface theme for your Godot projects! It has a retro 1990's look that's reminiscent of CDE (think: Windows 95 era computing).

The font used is ProggyClean by Tristan Grimmer.

I hope it is useful for you. I intend to continue working on it, and develop a set of little applications with it. If you have any difficulties with it, or want to make any requests, please, do tell me. :)

Check it out on [itch.io](https://softwave.itch.io/godot-retro-theme-space-worm).
